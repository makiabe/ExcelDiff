What is compared and current limits

Compare stored XLSX values, data types, formulas, standard cell formatting (fill, font, borders, alignment and number formats), merged cells, and row or column dimensions. Evaluated conditional formatting, images, shapes, comments, link destinations, print settings, table styles and macros are not compared.

Formulas are not recalculated. CSV is read as text to preserve leading zeros. XLS uses a compatibility reader and supports number-format comparison only. Safety limits: 50 MB and 500,000 cells per file, and 2 million cell pairs per sheet. Data beyond these limits is not silently omitted.

How to compare Excel files

Frequently asked questions

Are my files uploaded to a server?

No. Reading, comparison and report generation all take place locally in your browser.

Can I compare an XLSX file with a CSV file?

Yes. A CSV file is treated as a workbook with one sheet. Comparisons involving CSV use text values; formatting and data types are not compared.

What is a primary key used for?

Choose a column such as a unique ID to match rows by their keys instead of their row numbers. This helps distinguish added, deleted and changed rows when their order changes.

Privacy

Excel Diff is a static web application. Selected files are never uploaded to an external server. XLSX and CSV are processed without downloading an external library. Only legacy XLS files require a compatibility library from a CDN; the spreadsheet itself is not transmitted.
